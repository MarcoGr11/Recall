# Product Vision

## Vision Statement

Для студентів і поліцейських, які проходять базову загальновійськову підготовку (БЗВП), наш продукт — мобільна платформа з ролями інструктор/курсант, яка дозволяє не просто здати тест один раз, а справді засвоїти й утримати знання завдяки адаптивному повторенню та реалістичним сценаріям прийняття рішень. На відміну від Moodle (одноразовий контроль) чи розрізнених тренажерів (тільки медицина, тільки стрільба), наш продукт поєднує всі 13 офіційних модулів БЗВП в одній системі з живим моніторингом прогресу.

## Vision Board

| | |
|---|---|
| **Vision** | Створити платформу теоретичної підготовки БЗВП, що забезпечує довгострокове утримання знань (не одноразовий тест) та дає інструктору живий контроль над засвоєнням матеріалу групою. |
| **Target Group** | • Студенти ЗВО, що проходять БЗВП<br>• Інструктори БЗВП (викладачі дисципліни)<br>• (Потенційно) військовослужбовці на курсах БЗВП поза ЗВО |
| **Needs** | 1. Знання, здані на тесті, швидко забуваються — немає механізму повторення<br>2. Інструктор не бачить прогрес засвоєння в реальному часі<br>3. Немає перевірки ситуативного мислення, лише механічні тести<br>4. Контент розрізнений по модулях, немає єдиної системи |
| **Product** | Мобільний застосунок з:<br>1. SM-2 адаптивним повторенням тем<br>2. Live-дашбордом інструктора (WebSocket)<br>3. Сценарним симулятором рішень (AI-генерація + модерація)<br>4. Курс-центричною моделлю ролей (owner/co-instructor/cadet) |
| **Цілі для диплому** | 1. Продемонструвати архітектурно грамотну, масштабовану систему<br>2. Показати технічну відмінність від наявних рішень (Moodle, LifesaverSIM)<br>3. Отримати позитивний відгук практика (консультація інструктора) |
