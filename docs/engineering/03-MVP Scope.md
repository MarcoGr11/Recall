# MVP Scope

## Killer Feature

Див. повний опис — [[08-Кілер-фіча (сценарії)]]

Коротко: сценарний симулятор рішень з розгалуженнями, чернетки яких генерує ШІ (Claude Haiku), а публікує лише після схвалення викладачем. Студент проходить реалістичний кейс (часто міжпредметний), після завершення бачить повний розбір своїх рішень з поясненнями.

## Must Have Features

| Функція | Опис | Чому в MVP |
|---|---|---|
| Реєстрація, авторизація, ролі | Вхід і розмежування доступу owner/co-instructor/student | Базова умова роботи системи |
| Створення курсу і запрошення | Засновник створює курс за предметом, запрошує кодом | Стартова точка основного сценарію |
| Проходження матеріалу і тестів | Текст/схеми, тести з рандомізацією | Основна навчальна цінність |
| SM-2 адаптивне повторення з пріоритизацією за сесією | Розрахунок дати наступного повторення теми з урахуванням дат іспитів усіх курсів студента | Ключова відмінність від Moodle, Anki, Quizlet |
| Live-дашборд викладача | WebSocket, прогрес групи в реальному часі | Ключова відмінність від існуючих рішень |
| Підтвердження засвоєння | `confirmed_by` на рівні теми/курсу | Формальний контроль з боку викладача |
| Сценарний симулятор + AI-генерація + модерація | Killer feature, див. вище | Головний диференціатор проєкту |
| AI-генерація тестів з лекцій | Викладач завантажує лекцію → чернетка тесту → модерація | Ключова функція для реального наповнення курсу (~15 лекцій/предмет) |
| Персональний план підготовки на день | Зведений список пріоритетів між усіма курсами студента | Прямий наслідок міжпредметної пріоритизації SM-2 |
| Флагманський модуль (evergreen-навички) | Git, алгоритми, мережі, БД, безпека зі стрік-механікою | Відповідає вимозі "ширший функціонал" від керівника |

## Should Have Features

| Функція | Опис | Чому не критично для старту |
|---|---|---|
| Push-нагадування за графіком SM-2 | Нагадування студенту повторити тему | Підсилює мотивацію, але базовий цикл працює і без цього |
| Теплова карта прогалин (heatmap) | Візуалізація засвоєння за матрицею предмет × тема | Аналітична надбудова над вже наявними даними SM-2/тестів |
| Двомовність контенту (укр/англ) | Повний переклад для флагманського модуля | Інтерфейс двомовний одразу, контент — поступово |
| Персоналізована генерація сценаріїв під слабкі теми | AI-генерація з урахуванням індивідуальних помилок студента | Перспектива розвитку, не MVP |
| Повна анімація всіх 11 evergreen-тем | Зараз 5 тем з повною Lottie-анімацією, решта — текст+тест | Виробництво анімацій — окремий ресурс часу, не програмування |
