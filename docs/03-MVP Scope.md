# MVP Scope

## Killer Feature

Див. повний опис — [[08-Кілер-фіча (сценарії)]]

Коротко: сценарний симулятор рішень з розгалуженнями, чернетки яких генерує ШІ (Claude Haiku), а публікує лише після схвалення інструктором. Курсант проходить реалістичний кейс (часто міжмодульний — тактика+медицина+зв'язок), після завершення бачить повний розбір своїх рішень з поясненнями.

## Must Have Features

| Функція | Опис | Чому в MVP |
|---|---|---|
| Реєстрація, авторизація, ролі | Вхід і розмежування доступу owner/co-instructor/cadet | Базова умова роботи системи |
| Створення курсу і запрошення | Засновник створює курс за модулем БЗВП, запрошує кодом | Стартова точка основного сценарію |
| Проходження матеріалу і тестів | Текст/фото/схеми (медицина — Lottie), тести з рандомізацією | Основна навчальна цінність |
| SM-2 адаптивне повторення | Розрахунок дати наступного повторення теми | Ключова відмінність від Moodle |
| Live-дашборд інструктора | WebSocket, прогрес групи в реальному часі | Ключова відмінність від існуючих рішень |
| Підтвердження засвоєння | `confirmed_by` на рівні теми/курсу | Формальний контроль з боку інструктора |
| Сценарний симулятор + AI-генерація + модерація | Killer feature, див. вище | Головний диференціатор проєкту |

## Should Have Features

| Функція | Опис | Чому не критично для старту |
|---|---|---|
| Push-нагадування за графіком SM-2 | Нагадування курсанту повторити тему | Підсилює мотивацію, але базовий цикл працює і без цього |
| Двомовність контенту (укр/англ) | Повний переклад для флагманського модуля (медицина) | Інтерфейс двомовний одразу, контент — поступово |
| Рандомізація складності сценаріїв під слабкі теми | Персоналізована AI-генерація на основі SM-2-даних | Перспектива розвитку, не MVP |
