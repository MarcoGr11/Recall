# Thesis Proposal — Retain

## 1. Робоча назва проєкту

Українською: Мультидисциплінарна платформа теоретичної підготовки з базової
загальновійськової підготовки (БЗВП) з адаптивним повторенням матеріалу та
сценарним тренажером прийняття рішень.

Англійською: Multidisciplinary BZVP Training Platform with Adaptive Spaced
Repetition and AI-Generated Branching Decision Scenarios.

## 2. Актуальність та проблематика

Зміст теоретичної підготовки за програмою БЗВП визначено Типовою програмою,
затвердженою Генеральним штабом Збройних Сил України 24.02.2025 (13 модулів,
90 академічних годин). На практиці заклади вищої освіти самостійно обирають
засіб доставки теоретичного матеріалу — зокрема, теоретична частина в рамках
цієї дисципліни в закладах вищої освіти може реалізовуватись через системи
управління навчанням на кшталт Moodle, які забезпечують лише одноразовий
контроль знань: після складання тесту матеріал не переглядається повторно,
а результат не супроводжується механізмом довгострокового утримання
інформації.

Дослідження ефекту інтервального повторення (spaced repetition) демонструє,
що одноразове тестування без подальшого повернення до матеріалу не
забезпечує стійкого закріплення знань у довгостроковій пам'яті. Крім того,
наявні профільні рішення (LifesaverSIM — індивідуальний тренажер виключно
з тактичної медицини; Prometheus "База: Сучасна військова підготовка" —
відеокурс без інтерактивної перевірки знань) не надають інструменту, який
поєднував би мультидисциплінарність, роль інструктора з можливістю
моніторингу групи в реальному часі та перевірку ситуативного мислення
(а не лише механічного запам'ятовування).

Проблема, що вирішується: відсутність програмного засобу, який забезпечує
довгострокове утримання теоретичних знань за програмою БЗВП через адаптивне
повторення та реалістичне моделювання прийняття рішень, з одночасним
наданням інструктору інструментів контролю засвоєння матеріалу групою
в реальному часі.

## 3. Сформована ідея продукту

Тип архітектури: кросплатформний мобільний застосунок (React Native) з
клієнт-серверною взаємодією через REST API та WebSocket, backend-монолітом
з виокремленою асинхронною обробкою фонових задач через чергу повідомлень.

Продукт реалізує курс-центричну модель управління доступом: користувач із
роллю засновника курсу створює навчальний курс за одним із модулів
програми БЗВП, запрошує співінструкторів і курсантів; роль користувача
визначається окремо в межах кожного курсу, а не глобально в системі.

## 4. Детальний опис функціоналу (Core Features)

1. Реєстрація та рольова модель доступу (засновник курсу / співінструктор /
   курсант) з розмежуванням прав на рівні кожного окремого курсу.
2. Проходження навчального матеріалу та тестів з рандомізацією порядку
   питань і варіантів відповідей.
3. Адаптивне повторення матеріалу за алгоритмом SM-2: розрахунок
   оптимального інтервалу до наступного повторення теми залежно від якості
   відповіді курсанта.
4. Моніторинг прогресу групи інструктором у реальному часі через
   WebSocket-з'єднання, без необхідності оновлення сторінки.
5. Формальне підтвердження засвоєння теми чи курсу інструктором з
   фіксацією в системі.
6. Сценарний тренажер прийняття рішень: інтерактивні розгалужені сценарії,
   що поєднують кілька навчальних модулів у межах одного кейсу, з
   поясненням наслідків кожного вибору.
7. Конвеєр асинхронної генерації чернеток сценаріїв засобами великої
   мовної моделі (Claude API) з обов'язковою модерацією (схвалення,
   редагування або відхилення) інструктором перед публікацією.

## 5. Попередній інструментарій та технологічний стек

**Мови програмування та фреймворки**
JavaScript/TypeScript, React Native (Expo) — крос-платформний мобільний
застосунок з єдиною кодовою базою для iOS та Android; Node.js, Express —
серверна частина.

**Архітектурні патерни**
Клієнт-серверна архітектура з розділенням на синхронний REST API
(CRUD-операції, автентифікація) та асинхронну обробку фонових задач через
чергу повідомлень (генерація сценаріїв великою мовною моделлю). Рольова
модель доступу, що прив'язана до сутності курсу (resource-based RBAC), а
не глобально до користувача.

**Бази даних**
PostgreSQL — основне реляційне сховище (користувачі, курси, теми,
результати тестів, SM-2-прогрес, сценарії); Redis — брокер черги
повідомлень (BullMQ).

**Інтеграції**
Claude API (модель Haiku) — генерація чернеток навчальних сценаріїв за
структурованим промптом; Socket.io — двонаправлений обмін даними в
реальному часі між клієнтом інструктора та сервером.

**DevOps-інструменти**
Docker та docker-compose — контейнеризація серверної частини, бази даних
та брокера черги для відтворюваності середовища розробки; GitHub Actions —
базовий CI-конвеєр (статичний аналіз коду, автоматичний запуск тестів при
кожному push).

**Безпека**
JWT (access + refresh токени) для автентифікації; шифрування з'єднань
(HTTPS, WSS); шифрування чутливих полів бази даних; обмеження частоти
запитів (rate limiting) на рівні API.
