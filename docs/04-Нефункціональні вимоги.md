# Нефункціональні вимоги (NFR)

| ID | Категорія | Вимога | Критерій перевірки |
|---|---|---|---|
| NFR-01 | Performance | Основні екрани завантажуються швидко | Не більше 2 сек на стандартному з'єднанні |
| NFR-02 | Role-based Security | Кожна роль має доступ лише до дозволених даних | Курсант не бачить чужі результати; co-instructor не може видалити курс; прямий запит до чужого ресурсу повертає 403 |
| NFR-03 | Reliability | Результати тестів, SM-2-прогрес, сценарії не втрачаються | 100% збережених записів доступні після повторного входу |
| NFR-04 | Real-time | Дашборд інструктора оновлюється без перезавантаження сторінки | Затримка WebSocket-оновлення не більше кількох секунд |
| NFR-05 | Data Security | Персональні дані захищені шифруванням і мінімізовані | HTTPS/WSS, шифрування чутливих полів; див. [[10-Безпека даних]] |
| NFR-06 | Compatibility | Коректна робота на різних Android-пристроях, включно зі старішими | Тестування на кількох версіях Android |
| NFR-07 | Cost Control | Вартість AI-генерації сценаріїв контрольована і логується | Кожен виклик логується (`generation_log`), у межах пробного/студентського кредиту |
| NFR-08 | Anti-cheating | Тести стійкі до списування | Рандомізація порядку питань і відповідей |

Пов'язано: [[03-MVP Scope]], [[10-Безпека даних]]
