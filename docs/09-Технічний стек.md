# Технічний стек

| Компонент | Технологія |
|---|---|
| Застосунок | React Native + Expo (Android/iOS одним кодом) |
| Backend | Node.js + Express |
| Real-time | Socket.io (WebSocket), захищене з'єднання WSS |
| БД сервера | PostgreSQL |
| Офлайн-сховище | SQLite (expo-sqlite) — під питанням, див. нижче |
| Анімації | Lottie (lottie-react-native) |
| Локалізація | i18next + react-i18next |
| Автентифікація | JWT (access + refresh token) |
| Генерація сценаріїв | Claude API (Haiku 4.5) — див. [[08-Кілер-фіча (сценарії)]] |
| Черга завдань | Redis + BullMQ — асинхронна генерація сценаріїв |
| Контейнеризація | Docker + docker-compose (backend, PostgreSQL, Redis) |
| CI/CD | GitHub Actions (лінт + тести на push) |

## DevOps-складова (для категоризації стеку в proposal.md)

Додано свідомо поверх мінімального MVP, щоб проєкт відповідав архітектурному рівню F2 (не "простий CRUD"). Деталі — [[14-DevOps (Docker, CI-CD, Queue)]].

## Офлайн-режим (під питанням)

Спочатку планувався офлайн-first (SQLite + синхронізація), виходячи з припущення про роботу в польових умовах без зв'язку.

Переглянуто: заняття БЗВП проходять в обладнаних навчальних класах університету (за офіційною програмою — стабільна інфраструктура) і студенти вже здають теорію через Moodle онлайн.
