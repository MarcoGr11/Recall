# Структура даних (фрагменти — потребує зведення в повну ER-схему)


```
users: id, ПІБ, phone, account_type, verified
courses: id, назва (предмет), owner_id
course_instructors: course_id, user_id, added_by, role (owner/co-instructor)
course_members: course_id, user_id (студенти)
invitations: course_id, invited_by, code, role_to_assign, expires_at
topics: id, course_id (nullable — NULL для evergreen-тем флагманського модуля), title_uk, title_en, content_uk, content_en, module_type ('exam' | 'evergreen')
question_attempts: id, user_id, question_id, test_attempt_id, is_correct, answered_at
test_results: id, user_id, topic_id, score, timestamp, confirmed_by
sm2_progress: user_id, topic_id, interval, ease_factor, next_review_date

scenario_templates: id, course_id, difficulty, generated_by (ai/human), status (draft/approved/rejected)
scenario_nodes: id, scenario_id, text, is_ending, outcome_type (success/fail), explanation
scenario_choices: id, node_id, text, next_node_id, is_correct, feedback_text
generation_log: template_id, prompt_used, model_used, input_tokens, output_tokens, cost_usd, reviewed_by

exam_schedule: id, course_id, exam_date (орієнтовна, вказує викладач), weight
user_streaks: user_id, topic_id (evergreen-тема), current_streak, longest_streak, last_practiced_date
lecture_materials: id, course_id, topic_id, uploaded_by, file_path, parsed_text, status (uploaded/parsed/failed)
generated_tests: id, source_material_id (nullable), topic_id, generated_by (ai/human), status (draft/approved/rejected)
test_questions: id, test_id, question_text, options_json, correct_answer, explanation
```

`account_type` — інформаційна мітка типу акаунта при реєстрації ('teacher' | 'student'), впливає лише на UX за замовчуванням; фактичні права доступу завжди визначаються через `role_in_course` (див. Rule-02), а не це поле.
