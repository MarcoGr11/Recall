# Структура даних (фрагменти — потребує зведення в повну ER-схему)

Статус: чернетка, не фінальна ER-діаграма. Див. [[13-TBD відкриті питання]].

```
users: id, ПІБ/позивний, phone, role_global, verified
courses: id, назва, owner_id, type (official/community — опційно на майбутнє)
course_instructors: course_id, user_id, added_by, role (owner/co-instructor)
course_members: course_id, user_id (курсанти)
invitations: course_id, invited_by, code, role_to_assign, expires_at
topics: id, course_id, weapon_platform_id (nullable), title_uk, title_en, content_uk, content_en
test_results: id, user_id, topic_id, score, timestamp, confirmed_by
sm2_progress: user_id, topic_id, interval, ease_factor, next_review_date
weapon_platforms: id, назва (АК-74 / М4А1 / ...)

scenario_templates: id, module_id, difficulty, generated_by (ai/human), status (draft/approved/rejected)
scenario_nodes: id, scenario_id, text, is_ending, outcome_type (success/injury/fail), explanation
scenario_choices: id, node_id, text, next_node_id, is_correct, feedback_text
generation_log: template_id, prompt_used, model_used, input_tokens, output_tokens, cost_usd, reviewed_by
```
