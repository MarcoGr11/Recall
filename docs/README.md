## Контроль якості документації

На кожен Pull Request у `main` workflow [docs-linter.yml](../.github/workflows/docs-linter.yml) перевіряє `docs/` і кореневий README:

- markdownlint ([.markdownlint.jsonc](../.markdownlint.jsonc)) — ієрархія заголовків, списки, таблиці, блоки коду;
- Vale ([.vale.ini](../.vale.ini), стиль `Recall`) — кирилична транслітерація ІТ-термінів і розмовний сленг (помилка), оцінні слова (попередження).

Протоколи [17-AI Insights.md](17-AI%20Insights.md) і [18-Supervisor Feedback.md](18-Supervisor%20Feedback.md) з перевірки виключено: вони містять дослівні промпти і звіти, які не редагуються.

Останній успішний запуск: [Docs Quality Gate #45504494237](https://github.com/MarcoGr11/Recall/actions/runs/45504494237). Локальна версія markdownlint-cli2 — 0.24.2, як у GitHub Action.
